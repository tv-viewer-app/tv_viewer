# WinGet Submission

## To submit to WinGet:
1. Fork https://github.com/microsoft/winget-pkgs
2. Create: manifests/t/TVViewerApp/TVViewer/2.20.13/TVViewerApp.TVViewer.yaml
3. Copy the yaml from this directory
4. Submit PR

## Or use wingetcreate:
```
wingetcreate submit --token <github-pat> TVViewerApp.TVViewer.yaml
```
