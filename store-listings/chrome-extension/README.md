# TV Viewer Chrome Extension

## Building
1. Open Chrome → chrome://extensions/
2. Enable "Developer mode"
3. Click "Load unpacked" → select this directory
4. Or zip this folder and upload to Chrome Web Store

## Publishing
1. Register at https://chrome.google.com/webstore/devconsole ($5 one-time)
2. Create new item → upload the .zip
3. Fill metadata from store-listings/chrome-extension/listing.md

## Icons needed
Generate from web/static/icon-512.png:
- icon-16.png (16x16)
- icon-48.png (48x48)
- icon-128.png (128x128)
